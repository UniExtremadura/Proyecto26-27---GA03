# US-17 · Integración de Outlook dentro del campus

- **Jira:** SCRUM-23
- **Épica:** EP-05
- **Prioridad:** Low (Could)
- **Sprint:** 4
- **Bloqueada por:** US-15, US-16

## Análisis

El correo se ofrece dentro del campus en `/correo`. La autenticación usa Microsoft Entra ID (OAuth 2.0, flujo de código de autorización). **Nunca se guardan secretos en el repositorio:** el identificador de inquilino y de aplicación se leen de las variables de entorno `M365_TENANT_ID` y `M365_CLIENT_ID`. Si no están configuradas, la página lo indica y ofrece abrir Outlook en una pestaña nueva. Pendiente fuera de este alcance: intercambio del código por un token (requiere el registro de la aplicación).
