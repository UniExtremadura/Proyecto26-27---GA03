## Análisis

Se entrega una **aplicación web progresiva (PWA)** bajo `/m/`: diseño *mobile-first*, instalable desde el navegador (manifiesto) y sin tiendas de aplicaciones. Flujo: **1)** inicio de sesión con usuario y contraseña → **2)** el cliente recibe un token (`/api/token`) y lo guarda solo durante la sesión → **3)** la pantalla de inicio consulta `/api/m/resumen` con ese token y muestra el resumen del alumno.
