# App de escritorio (US-12)

Cliente mínimo en Tkinter que se autentica contra la API del campus.

```bash
python run.py                       # en una terminal: servidor del campus
python -m desktop.app               # en otra: abre la ventana de acceso
python -m desktop.app http://127.0.0.1:5000
```

Usuarios de demostración: ver `docs/desarrollo.md`.
